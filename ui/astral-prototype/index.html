Study design and boundaries
What this NASA dataset can support

Inspiration4 was a three-day low Earth orbit mission with four crew members. This CMP file contains seven serum collection times: L−92, L−44, L−3, R+1, R+45, R+82, and R+194. The samples are pre-flight and post-flight, not continuous in-flight monitoring.

ASTRAL RESPONSE

A simple review sequence

The system supports the astronaut's decision; it does not make a diagnosis.

01

Check the measurement.Pause, follow the device instructions, and repeat a value that seems unexpected.

02

Review the pattern.ASTRAL SENSE and INTELLIGENCE show changes against your own history; the method is visible and reproducible.

03

Check the context.ASTRAL ENVIRONMENT keeps mission conditions separate from personal measurements. A relationship is not proof of cause.

04

Use the mission protocol.For persistent changes or concerning symptoms, follow the onboard checklist and contact the flight surgeon when possible.

Prototype limits
Visible limits are part of responsible health software.
01

No clinical validation.The rolling median / MAD pattern rule is illustrative and not clinically validated.

02

No diagnosis or causal inference.Signals prompt verification and approved procedures.

03

No live sensor feed.OSD-575 measurements appear only in the separate Biology view; crew entry and habitat demo values are synthetic.

04

No safety-critical control.The software does not operate lighting, spacecraft systems, or task assignments.

05

Separate research-model sandbox.This browser includes the WESAD model weights and a synthetic feature-vector demo. It does not read crew entrys or live signals; laboratory results do not establish astronaut validity.

Data handling
Offline by design for this demonstration.

This browser stores the user's demo entries in local storage. No account, analytics, server, external API, or crew data sharing is implemented. Select Clear local demo data below to delete the entries from this browser.
