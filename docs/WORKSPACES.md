## Workflow
1. Accept the repository collaborator invitation.
2. Bookmark your workspace link and review your assigned issue.
3. Work on your assigned branch; confirm the branch dropdown before committing.
4. When ready, open a pull request targeting `main` and request review.
5. If `main` moves forward, update your branch before merging. Branches do not synchronize automatically.

**Note:** The workspace link is a convenience, not an access restriction. Collaborators with write access may edit other folders. Coordinate shared files and review pull requests.
